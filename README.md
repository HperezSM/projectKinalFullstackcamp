# Project Kinal — Full Stack Bootcamp

Full stack Java web application developed during the Kinal Full Stack Bootcamp.

## Overview

An ongoing full stack project built as part of a structured bootcamp curriculum. Covers backend API development, database design, and frontend integration using Java-based technologies.

## Tech Stack

- **Language:** Java
- **Backend:** Spring Boot / Java EE
- **Database:** MySQL / PostgreSQL
- **Frontend:** HTML, CSS, JavaScript

## Features

- RESTful API design
- CRUD operations
- User authentication
- Database integration

```bash
# Clone the repo
git clone https://github.com/HperezSM/projectKinalFullstackcamp.git

# Import into your IDE (IntelliJ / Eclipse)
# Configure database credentials in application.properties
# Run the application
```
